## Core mark

Dual luminous crescents (eclipse / threshold) — violet outer body with solar-gold inner glow on midnight.

## Wordmark & tagline (brand board)

- Wordmark: lowercase **inphase** (Cinzel)
- Tagline: **NAVIGATE RELATIONSHIPS WITH GREATER CLARITY, CONNECTION, AND UNDERSTANDING.**

Product / App Store naming remains **InPhase** (PascalCase). Platform tagline *She's not complicated. She's cyclical.* remains valid for product constitution surfaces — see [`../../products/inphase.md`](../../products/inphase.md).

## Usage (from brand board)

- Clear space ≈ height of lowercase **n** in the wordmark
- Minimum size: 32px digital / 12mm print
- Do not stretch, rotate, recolor, add drop shadows, or place on busy backgrounds
- Symbol-only for small icons; lockups when name should appear
