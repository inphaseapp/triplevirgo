# MyPhase Brand Assets

Imported from the official `MyPhase_Brand_Assets` pack. Source artwork is preserved — no logo regeneration.

## Source of truth

The gemstone emblem in `01_Master` and presentation board in `06_Brand_Reference` are the visual masters.

## Core mark

Two polished gemstone crescents:

- **Left:** White Moonstone / warm pearl — Awareness  
- **Right:** Rose Quartz / milky blush pink — Self-Love  

**Tagline:** Know yourself. Love yourself.

## Usage

- Prefer the transparent emblem for flexible layouts
- Use Charcoal avatar when a finished square is needed
- Use dark/light lockups when name + tagline should appear together
- Do not recolor, stretch, rotate, separate, or redraw the gemstone crescents
- Maintain clear space around the mark
- For very small uses, use the emblem without wordmark/tagline
